# Docs Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the story gallery into an Ant-style docs site (overview + one page per module) whose props, example code, tokens, changelog and LLM files are generated from source, plus two tested skills that keep it that way.

**Architecture:** A Node generator (`scripts/docs-gen/`) parses emitted `.d.ts` and source with `oxc-parser`, fills marked regions of `docs/**/*.md`, rewrites the `AGENTS.md` docs index, and writes `gallery/generated/site-data.json`. The Vite app in `gallery/` reads that JSON plus `src/**/examples/*.tsx` (eager glob) and renders pages; demos run in an iframe route. `docs:check` fails on any stale output.

**Tech Stack:** Node 24 (mise, `.node-version`), TypeScript 7 (tsgo, no JS API), Vite 8, React 19, react-jss, react-router 8 (HashRouter), vitest 4 + Testing Library, `node --test` for scripts, new dev deps `oxc-parser` and `marked`.

**Spec:** `docs/superpowers/specs/2026-11-25-docs-site-design.md`

## Global Constraints

- No runtime `dependencies`; `oxc-parser` and `marked` are `devDependencies` only. No `typescript@5`, no Go.
- Nothing site-related ships: `files`, `tsconfig.build.json` and `scripts/smoke-exports.sh` exclude `src/**/examples/**` (and still `*.stories.*` until they are gone).
- Examples import from public entry points (`@korzun/design/control`, `/component`, `/theme`, `/icon`, `/toast`, `/hooks`), never relative paths. Everything else keeps the relative-imports rule.
- Examples follow AGENTS.md styling rules: tokens only, `Stack`/`Inline`/`Text`/`Heading` for layout and text, no literal colours/px.
- Categories (exact, closed list): `Layout`, `Typography`, `Actions`, `Inputs`, `Overlays`, `Feedback`, `Data display`, `Navigation`, `Theme`; guides use `Guide`.
- Changelog bullet tag form: `- [Button, Menu] text` or `- [General] text`; nested sub-bullets inherit their parent's tags.
- Everything lands on branch `docs-site` and merges once as **0.5.1**; GitHub Pages keeps the old gallery until then.
- Run `npm run lint` (oxfmt check) before every push; CI has failed on formatting before.
- Site hosting unchanged: `.github/workflows/gallery.yml`, hash routing, base `/korzun-design/`.

## Review Focus

1. **`|` inside a type** (`'default' | 'primary'`) breaks a markdown table: every generated table cell escapes `|` as `\|` (test in Task 5).
2. **Prop in only some union branches** (`ButtonProps` `danger`/`success` via `ButtonVariant`): listed once, with the JSDoc of the first branch that documents it, type is the union of its branch types minus `undefined`/`false`-only branches. (`danger` → `boolean`) (test in Task 1).
3. **`interface X extends Y`** (`SurfaceProps` is an interface) and props from an imported type: flattened like aliases (test in Task 1).
4. **A doc missing a region marker or with markers out of order**: the generator throws naming the file and the missing marker; it never appends or silently skips (test in Task 5).
5. **Running `docs:gen` twice** produces no diff, and `docs:check` passes right after `docs:gen` (test in Task 6).
6. **Search for a term with no match or different case**: case-insensitive; no match shows "No components match “x”." (test in Task 9).

```

  defaults.mjs       readDefaults(): destructuring defaults from index.tsx
  tokens.mjs         collectTokenPaths(), resolveTokens()
  changelog.mjs      parseChangelog(), validateTags()
  examples.mjs       readExample()
  front-matter.mjs   parseFrontMatter()
  regions.mjs        renderRegions(), replaceRegions(), stripRegions()
  inventory.mjs      listModules(): barrels → ModuleInfo[]
  generate.mjs       generate(repo) → Map<path, content>
  cli.mjs            `node scripts/docs-gen/cli.mjs [--check]`
  *.test.mjs         one per module above
gallery/
  app.tsx            routes (rewritten)
  data.ts            typed site data + example component map
  frame.tsx          renders one example in the iframe
  search.ts          filterModules()
  llms-plugin.ts     Vite plugin: llms.txt, llms-full.txt, raw docs
  generated/site-data.json   (generated, committed)
  layout/header.tsx
  page/{overview,component,changelog,guide,tokens}.tsx
  part/{example-block,props-table,tokens-table,markdown,copy-button,thumbnail,icon-grid}.tsx
src/<area>/<module>/examples/NN-slug.tsx
.claude/skills/{document-component,new-component}/SKILL.md
```

Shared data types (defined in `scripts/docs-gen/types.d.ts` as JSDoc-importable TS types, and mirrored by `gallery/data.ts` importing the JSON):

```ts
type PropRow = { name: string; type: string; required: boolean; default?: string; description: string; deprecated?: boolean };
type TypeTable = { name: string; kind: 'props' | 'object' | 'alias'; rows: PropRow[]; text?: string }; // text: alias source for kind 'alias'
type TokenRow = { path: string; kind: 'color' | 'recipe' | 'value'; light: string | null; dark: string | null };
type ChangelogEntry = { version: string; date: string; tags: string[]; text: string }; // text keeps sub-bullets as markdown
type ExampleInfo = { file: string; slug: string; order: number; title: string; description: string; code: string };
type ModuleInfo = {
  id: string;            // 'control/button' | 'component/alert' | 'theme' | 'toast' | 'icon'
  slug: string;          // 'button'
  entry: string;         // '@korzun/design/control'
  docPath: string;       // 'docs/control/button.md'
  title: string; description: string; category: string;
  values: string[]; types: string[];   // public names this module exports
  importLine: string;
  body: string;          // hand-written markdown: doc minus front matter, H1 and generated regions
  examples: ExampleInfo[]; tables: TypeTable[]; tokens: TokenRow[]; changelog: ChangelogEntry[];
};
type Guide = { slug: string; docPath: string; title: string; description: string; body: string };
type SiteData = { version: string; modules: ModuleInfo[]; guides: Guide[]; changelog: { version: string; date: string; entries: ChangelogEntry[] }[] };
```
