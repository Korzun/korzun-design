# Slider Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A general single-value `Slider` control with arbitrary detents, start/end labels and a custom thumb, accessible by keyboard, able to replace Bookplate's chapter slider.

**Architecture:** Pure snapping maths in `snap.ts` (unit-tested alone), a component in `index.tsx` that renders track, fill, ticks and a focusable `role="slider"` thumb wrapper, with pointer capture for dragging and a key handler, and a hidden input for forms.

**Tech Stack:** React 19, react-jss (`createUseStyles`), Vitest + Testing Library (jsdom), oxfmt, oxlint.

**Spec:** `docs/superpowers/specs/2026-11-28-slider-design.md`

## Global Constraints

- Lives at `src/control/slider/`, exported from `src/control/index.ts` as `Slider`, `SliderProps`, `SliderDetent`, `SliderThumbState`.
- Relative imports to module folders only; no runtime dependencies.
- Every prop has JSDoc; defaults as literals in the destructuring.
- `style.ts`: tokens only; every remaining literal listed in a comment block at the top with its reason. Focus ring is `...theme.recipe.focusRing` with `outlineColor` set on `:focus-visible` only.
- Default look follows Bookplate: 40px-tall hit area, 4px track (2px radius), brand fill, 2×14px ticks (brand at or below the value), 18px brand circle thumb with `0 1px 4px rgba(0,0,0,.2)`, labels `fontSize.xs` `text.faint` `space.xs` below.
- Snap animation 0.15s ease on thumb `left` and fill `width`, off under `prefers-reduced-motion: reduce`.
- LTR only. Version stays 0.7.0 (unreleased); CHANGELOG bullet tagged `[Slider]`.
- Stage with `git add -A -- . ':!node_modules'`. No force-push.

## Review Focus

1. A `value` outside `[min, max]` or not finite: clamped for drawing and ARIA, never NaN in styles.
2. `step={null}` with no detents: falls back to `min` and `max` as the only snap points, never throws.
3. `max <= min`: treated as a range of one (`max = min + 1`) so no divide-by-zero.
4. Disabled during a drag (prop flips mid-drag): no more `onChange`; the drag ends cleanly.
5. A custom `thumb` that returns a large node: the wrapper stays centred on the value and keeps at least a 24px hit area.

### Task 1: Snapping maths

**Files:**
- Create: `src/control/slider/snap.ts`
- Test: `src/control/slider/snap.test.ts`

**Interfaces:**
- Produces:
  - `snapPoints(min: number, max: number, step: number | null, detents: number[]): number[]`: sorted, deduplicated, all within `[min, max]`. A number step gives `min, min+step, …` (≤ max) plus `max` plus every detent. `null` gives the detents, or `[min, max]` when there are none.
  - `nearest(points: number[], v: number): number`
  - `nextPoint(points: number[], v: number, dir: 1 | -1): number`: the first point strictly beyond `v` in `dir`, or `v`'s nearest end point when none.
  - `clampRange(min: number, max: number): [number, number]`: returns `[min, max > min ? max : min + 1]`.

- [ ] **Step 1: Write the failing tests** in `snap.test.ts`:
  - `snapPoints(0, 10, 5, [])` → `[0, 5, 10]`; `snapPoints(0, 10, 3, [])` → `[0, 3, 6, 9, 10]`; `snapPoints(0, 100, 50, [12])` → `[0, 12, 50, 100]`.
  - `snapPoints(0, 100, null, [80, 12, 12, 150])` → `[12, 80]` (deduped, sorted, out-of-range dropped); `snapPoints(0, 100, null, [])` → `[0, 100]`.
  - `nearest([0, 12, 80], 40)` → `12`; `nearest([0, 12, 80], 50)` → `80`.
  - `nextPoint([0, 5, 10], 7, 1)` → `10`; `nextPoint([0, 5, 10], 7, -1)` → `5`; `nextPoint([0, 5, 10], 5, 1)` → `10`; `nextPoint([0, 5, 10], 10, 1)` → `10`.
  - `clampRange(5, 5)` → `[5, 6]`; `clampRange(0, 10)` → `[0, 10]`.

### Task 2: The component: render, ARIA, keyboard, form

**Files:**
- Create: `src/control/slider/index.tsx`, `src/control/slider/style.ts`
- Test: `src/control/slider/index.test.tsx`

**Interfaces:**
- Consumes: Task 1's functions.
- Produces:
  ```ts
  export type SliderDetent = { value: number; label?: ReactNode };
  export type SliderThumbState = { value: number; dragging: boolean; focused: boolean; disabled: boolean };
  export type SliderProps = {
    value: number; onChange: (value: number) => void; onChangeEnd?: (value: number) => void;
    min?: number; max?: number; step?: number | null; detents?: SliderDetent[];
    startLabel?: ReactNode; endLabel?: ReactNode;
    thumb?: (state: SliderThumbState) => ReactNode;
    ariaLabel: string; ariaValueText?: (value: number) => string;
    disabled?: boolean; name?: string; className?: string; ref?: Ref<HTMLDivElement>;
  };
  ```
  Defaults: `min = 0`, `max = 100`, `step = 1`, `disabled = false`. `ref` and `className` on the root. The thumb wrapper has `data-testid="slider-thumb"`; ticks `data-testid="slider-tick"` with `data-active` when at or below the value.

  - `ariaValueText={(v) => \`Chapter ${v}\`}` sets `aria-valuetext="Chapter 30"`.
  - clamps: `value={150}` gives `aria-valuenow="100"` and the thumb's `style.left` `100%`; `value={NaN}` gives `0` and `0%`.
  - keyboard: after `user.tab()` the slider is focused; ArrowRight calls `onChange(31)` then `onChangeEnd(31)`; ArrowLeft `29`; ArrowUp `31`; ArrowDown `29`; Home `0`; End `100`; PageUp `40`; PageDown `20` (10% of the range, snapped).

  - detents only: `step={null} detents={[{value:12},{value:40},{value:80}]} value={12}` ArrowRight → `40`, PageUp → `40`, End → `80`, Home → `12`.
  - no change, no call: `value={100}` End calls neither handler.
  - controlled: after ArrowRight with an `onChange` that does nothing, `aria-valuenow` stays `30`.
  - detents draw ticks: three detents at 12/40/80 with `value={40}` render 3 `slider-tick`s, the first two `data-active`; a detent at `0` or `100` draws no tick but its label renders.
  - labels: `detents={[{value:50,label:'Half'}]} startLabel="Start" endLabel="End"` renders all three texts.
  - custom thumb: `thumb={(s) => <span>v{s.value}</span>}` renders `v30` inside the `slider` element and no default circle (`[data-testid="slider-knob"]` absent).
  - disabled: `aria-disabled="true"`, `tabindex` `-1`, keys call nothing.
  - form field: inside a `<form>`, `new FormData(form).get('progress')` is `'30'` for `name="progress"`.
  - className and ref land on the root.
