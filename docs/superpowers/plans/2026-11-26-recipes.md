# Recipes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "recipes" to the docs: assemblies of library parts, each with live
previews and generated code. Ship the first one, Sign in, along with a new
`theme.layout.formWidth` token.

**Architecture:** A recipe is two things:
- `docs/recipes/<slug>.md`, with front matter `category: Recipe` and only an
  `examples` generated region
- one or more `recipes/<slug>/NN-slug.tsx` files at the repo root

`docs-gen` collects recipes into `site.recipes` and fills each doc's examples
region. The docs site renders `#/recipes` and `#/recipes/:slug`, reusing
`ExampleBlock` and `Thumbnail`. These now take an `ExampleOwner` (a module or a
recipe) whose `framePath` picks the frame route:
- modules: `/frame/:module/:example`
- recipes: `/frame/recipe/:recipe/:example`

**Tech Stack:** React 19, react-jss, react-router 8, Vite, Vitest + Testing
Library, `node --test` for `scripts/`.

**Spec:** `docs/superpowers/specs/2026-11-26-recipes-design.md`

## Global Constraints

- Recipe examples import only from public entry points (`@korzun/design/control`, `/component`, `/theme`, `/toast`); no relative imports into `src`.
- Recipe code obeys AGENTS.md:
  - no literal px, rem or hex
  - no `radius` or `surface` props
  - layout with `Stack`/`Inline`, text with `Text`/`Heading`
  - styles via `createUseStyles((theme: Theme) => …)`, tokens only
- The styles go at the top of the example file, not in a sibling `style.ts`, so the generated doc code is complete. Precedent: `src/component/surface/examples/01-basic.tsx`.
- `recipes/` never ships. `docs/recipes/*.md` does.
- `formWidth` value: `'400px'`.
- `Recipe` is not added to `CATEGORIES`.
- Recipe docs have exactly one generated region, `examples`.
- Version `0.6.0`. CHANGELOG lines start with `[Theme]` and `[General]`.
- Never edit inside a `<!-- generated:… -->` region by hand; run `npm run docs:gen`.

## Review Focus

1. **A full-height (`100vh`) recipe in a self-sizing frame.** The frame posts its content height, the iframe grows, and `100vh` grows with it, so the frame never settles. Expected: a fixed-height preview. Pinned by the `@viewport screen` tests in Task 3.
2. **A doc link to `docs/recipes/login.md` from a guide or a module doc.** Today `docHref` maps it to `#/components/login`. Expected: `#/recipes/login`. Pinned in Task 3.
3. **A recipe slug equal to a module slug** (a future `recipes/dialog/`). Expected: each frame still renders its own example. Pinned by the frame-route test in Task 3.
4. **Pressing Enter in the password field.** Expected: the form submits, because Sign In is a real submit button inside the `<form>`. Pinned in Task 4.
5. **A recipe folder with no doc, or a doc with no folder or no examples.** Expected: `docs:gen` fails loudly, naming the path, rather than silently skipping it. Pinned in Task 2.

**Interfaces:**
- Produces:

```ts
export type Recipe = {
  slug: string;        // basename of docs/recipes/<slug>.md == folder recipes/<slug>/
  docPath: string;     // 'docs/recipes/<slug>.md'
  title: string;
  description: string;
  body: string;        // H1 and generated regions stripped, trimmed
  examples: ExampleInfo[]; // file: 'recipes/<slug>/NN-slug.tsx', sorted by order
};
// SiteData.recipes: Recipe[], sorted by slug
```

- `replaceRegions(md, mod, file, ctx = {}, names = REGIONS)`

**Generator rules:**
- `checkCategory` accepts `Recipe` for non-module docs, the way it accepts `Guide`.
- A `category: Recipe` doc outside `docs/recipes/` throws.
- So does a `docs/recipes/*.md` whose category isn't `Recipe`.
- Examples are read from `recipes/<slug>/*.tsx` with `readExample`. Generalise `readExamples` to take a directory and a repo-relative prefix.
- The doc is rewritten with `replaceRegions(content, recipe, docPath, {}, ['examples'])`, keeping the front-matter head, as for modules.

**Errors:**

| Condition | Message |
| --- | --- |
| A recipe doc with no folder, or no `.tsx` in it | `docs/recipes/<slug>.md: no examples in recipes/<slug>/` |
| A folder in `recipes/` with no doc | `recipes/<slug>/: no docs/recipes/<slug>.md` |

Both throw always, not only in strict mode. A missing `recipes/` directory means there are no recipes, not an error.
